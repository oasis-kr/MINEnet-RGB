RGB GRADIENTER

마인크래프트 RGB 그라데이션 시스템

📖 사용 가이드 (How To Use)

본 시스템은 마인크래프트 내에서 사용되는 다양한 헥사(Hex) RGB 코드를 쉽고 정밀하게 조합하여 아름다운 연출을 도와주는 도구입니다.

  1. 텍스트 입력: INPUT TEXT 란에 인게임에 적용하고 싶은 문구를 작성합니다. 한글 도트 폰트를 지원합니다.
  2. 컬러 팔레트 지정: 기본 3가지 색상 외에 ➕ ADD COLOR를 눌러 멀티 그라데이션 포인트를 무제한으로 확장할 수 있습니다.
  3. 스타일 및 포맷 선택: 마인크래프트 플러그인 환경(CMI, EssentialsX, 순정 등)에 호환되는 올바른 출력 포맷을 지정합니다.
  4. 복사 및 적용: 하단의 복사 버튼을 누르고 게임 내 채팅창, 칭호 설정창, 혹은 서버 컨피그(Config) 파일에 붙여넣어 즉시 적용합니다.

❓ 자주 묻는 질문 (FAQ)

Q1. 볼드(&l) 효과를 주니 글자가 겹쳐 보여요. 에러인가요?

아닙니다. 웹 브라우저 화면의 렌더링 방식에 따른 일시적 현상일 뿐이며, 실제 생성된 코드를 복사하여 마인크래프트 게임 내에 적용하시면 정상적으로 출력됩니다.

Q2. 어떤 출력 포맷 형식을 선택해야 하나요?

최신 플러그인(CMI, EssentialsX 등) 환경은 대다수 <#RRGGBB> 혹은 &#RRGGBB 구조를 채택합니다. 플러그인이 없는 바닐라 순정 상태라면 &x 방식을 선택하세요.

Q3. 입력한 데이터가 외부 서버에 저장되나요?

아닙니다. 모든 연산은 클라이언트 브라우저 내부에서 작동하며 외부 서버로 전송되지 않습니다.
